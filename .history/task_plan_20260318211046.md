## 任务目标
开发一个名为 `devdash` 的命令行工具，集成多种开发辅助功能，帮助开发者快速了解项目状态。

## 使用方式设计
```bash
devdash                    # 显示项目概览
devdash git               # 显示Git状态
devdash stats             # 显示代码统计
devdash todo              # 显示TODO列表
devdash log "修复了bug"   # 记录日志
devdash log --today       # 显示今日日志
devdash health            # 项目健康检查
```
